## Class Structure

### [puzzle8.py](./puzzle8.py)

Complete class of 8 Puzzle board that allows:

- Gets possible actions based on current state
- Moves empty space one time and returns another instance of 8 Puzzle board with new state
- Represents board in both string and pretty formats

### [Heuristics](./heuristics/)

Contains a base class [Heuristic](./heuristics/base.py) that gives an interface for heuristic implementations.

Implementations include:

- [Manhattan](./heuristics/manhattan.py)
- [Euclidean](./heuristics/euclidean.py)

### [node.py](./node.py)

Complete class for a node in a general search tree used to keep track of the current board state
generated by any AI agent.

Contains attributes such as:

- Parent Node
- Current board state (8 Puzzle Board)
- Action that led to current state
- Accumulated path cost g(n)
- Depth of search tree (how many nodes before the current node)

For A* AI agent:

- Heurestic value h(n)
- Total of heuristic and path cost f(n) = g(n) + h(n)

Can be used to construct goal path, actions taken to goal path, total cost of path, depth of path.

## Setup

1. Make sure you have Python installed by checking its version in the terminal

    ```bash
        python --version
    ```

2. Make sure you are using VS Code and have the Jupyter Extension installed (Jupyter by Microsoft)

3. Create a virtual environment to contain the packages needed for this assignment, use the built-in **venv** package:

    ```bash
        python -m venv env
    ```

4. Activate the virtual environment using this command, depending on your OS:

    - **Linux**

    ```bash
        source env/bin/activate
    ```

    - **Windows**

    ```bash
        env\Scripts\activate.bat
        # OR if in Powershell
        .\env\Scripts\Activate.ps1
    ````

5. Install the requirements:

    ```bash
        pip install -r requirements.txt
    ```
